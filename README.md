# The Cold Box — AI-Powered Food Inventory System

The Cold Box is an AI-powered smart inventory and expiry tracking system designed to reduce household food waste through produce recognition, expiry reminders, and intelligent inventory management.

## Inspiration

This project was inspired by a real-life problem observed at home where produce stored inside refrigerators was often forgotten due to busy schedules, leading to unnecessary food waste.

The long-term vision explores integrating AI and computer vision directly into smart refrigerators for real-time freshness monitoring.

---

## Problem Statement

Food waste is a common household issue caused by:
- forgotten produce
- lack of inventory visibility
- manual tracking effort
- absence of intelligent reminder systems

The Cold Box aims to simplify inventory management through AI-powered workflows.

---

## Features

- Produce inventory tracking
- Expiry reminders
- Image-based produce recognition

## AI Workflow

### Image Classification

- fruit identification

### Freshness Prediction Exploration

- visual texture
- color changes
- image-based analysis

---

## Product Thinking

### User Pain Points
- Users forget produce inside refrigerators
- Existing inventory apps require manual effort
- No simple way to track freshness

### Product Decisions
- Mobile-first MVP approach
- Reduced friction through image recognition
- Prioritized reminders over complex AI initially
- Simple workflows for consistent adoption

---

## Challenges Faced

### Dataset Limitations
Limited datasets for freshness prediction.

### User Retention
Reducing friction in daily inventory tracking.

### AI Complexity
Balancing lightweight models with usability.
